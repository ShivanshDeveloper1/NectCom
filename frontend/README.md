# Ayurvedic-web-ui

React 18 + Tailwind CSS v4 + React Router v7 frontend for Krishna's Herbal & Ayurveda E-Commerce Platform.

## Backend Connection
Connected to live Render backend: `https://ayurvedic-backend-xpb5.onrender.com`

## Quick Start
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
